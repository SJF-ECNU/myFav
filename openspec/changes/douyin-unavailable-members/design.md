# MCP服务实现计划

目标：保留完整性校验，解释既有失效作品导致的计数占位，恢复其余收藏同步。
边界：仅核验当前指定收藏范围中的既有成员；未知条目不补造；保留身份、分页去重、计数变化、平台拒绝守卫。
方案：差额必须恰等于旧成员中的缺项，逐条取得匹配ID的status_deleted证据，最后复核收藏夹身份及计数。占位标记metadataStatus=unavailable、membershipStatus=previously_confirmed，不发起后续文本/图片准备，历史缓存可仅读。同步报告不可用数。
验证：模拟正常/失效/无证据/错误ID/403/计数变化/未知差额；生产网页同源对照、完整同步与占位准备不访问平台。
