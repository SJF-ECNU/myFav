# 平台拒绝、收藏范围及缓存清理
保留 CloakBrowser。平台明确拒绝/验证码/登录失效时持久暂停，429按 Retry-After（至少15分钟）冷却；通过本地CLI显式恢复。浏览器/API/字幕/媒体共享同一平台状态。失败不能触发绕行下载。
任务执行前与缓存落库前复核当前收藏；成功同步移除条目时记录移除时间，保留正文、字幕、图片与签名来源7天，期内重新收藏恢复完整缓存，到期自动清理，保留元数据、事件和Agent结果。超过保留期后重新收藏不复用旧缓存；旧的未完成任务仍不得在重新收藏后写回。范围以最后成功同步为准，未同步的平台变化无法实时知道。
不新增定时监测、不替换浏览器、不变更OAuth或多用户模型。本轮完成代码与测试，部署与推送不包含在本次请求中。
